# hxyfront-62004 蜡材批次排工台

面向滑雪板调校店的蜡材批次排工台。旺季多台调校机共享蜡材库存，页面不再只按板子填表——选蜡的同时能看到每个批号的余量。

## 功能

- **工单登记**：板型、板长、刃角、客户偏好、底板损伤，登记后进入「待备料」
- **蜡材库存**：按蜡型 + 批号管理，余量进度条、低量/用完警示，支持入库补货与新增批次
- **开工扣蜡**：按 `板长 × 蜡型费率(g/cm)` 计算用量并扣减批号库存；余量不足时工单停在「待备料」并写明缺量
- **复核流转**：打蜡后改刃角或补记损伤会退回「待复核」，已扣的蜡不退回库存；再次打蜡必须更换批号
- **交付留档**：交付后写入客户历史，保留每一次用量（蜡型、批号、克数、时间）
- **本地持久化**：库存、工单、历史保存在 localStorage，关掉浏览器再打开仍在
