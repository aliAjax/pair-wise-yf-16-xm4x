# 蜡材批次排工台 · 滑雪板调校店

旺季多台调校机共享几箱蜡材时的批次排工前端。React + Vite + TypeScript，纯前端、数据存
`localStorage`（key：`wax-workbench-v1`），关闭浏览器再打开，库存、工单和客户历史仍在。

## 业务规则

- **开工登记**：板型、板长（cm）、刃角、底板损伤、修补位置、客户偏好。
- **开工前选蜡**：选蜡型 + 批号，按板长整板扣库存，规则 `板长 cm × 1 g`。
- **余量不足**：不扣蜡，工单停在「待备料」，写明批号、需量、存量、缺量；补货后可重新选蜡开工。
- **打蜡后复核**：改刃角或补记底板损伤会把工单退回「待复核」并要求重新确认；**已扣的蜡不退还**。
- **再次打蜡**：必须换另一个批号（本单已用批号在下拉中禁用），每次扣料单独留痕。
- **交付**：复核通过后交付，客户历史按人保留每次打蜡的蜡型、批号、用量与板长。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62004。构建：`npm run build`。

页面右上角「恢复示例数据」会清空本地数据并重置为示例批次与工单。
